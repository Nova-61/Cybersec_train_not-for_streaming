# Обзор пройденных тем: Day 1–30

Этот единственный файл содержит краткий и понятный обзор тем, которые вы уже прошли в проекте по дням.
Он заменяет любые дополнительные `README.md` в `Day_*` папках — всё теперь в одном месте.

## Как пользоваться

- Открывайте папки `Day_1`, `Day_2`, ..., `Day_30` чтобы увидеть конкретный код.
- Здесь описано, какие темы и идеи изучались в каждом дне.
- Если нужно вспомнить, что делать с конкретной темой, ищите день в разделе ниже.

## Что важно помнить

- Go строится вокруг `func main()`, пакетов и модулей (`go.mod`).
- Интерфейсы и типы дают гибкость: `interface`, `struct`, методы.
- Конкурентность — это каналы, горутины, `sync.Mutex` и `sync.WaitGroup`.
- HTTP-приложения — это обработчики, middleware и безопасные маршруты.
- Базы данных: подключение, пул, SQL-запросы и `sqlx`.
- Тесты помогают фиксировать поведение и находить баги.
- Нагрузочное тестирование показывает, как приложение ведёт себя под пиковыми запросами.

## Как ориентироваться

- Ищите нужный день по теме:
  - `Day_1`–`Day_5` — основная логика и синтаксис Go.
  - `Day_6`–`Day_9` — интерфейсы, структуры, пакеты и каналы.
  - `Day_10`–`Day_14` — параллельность, таймауты, worker pools.
  - `Day_15`–`Day_20` — веб-серверы, HTTP, файлы и API.
  - `Day_21`–`Day_26` — тестирование, базы данных, безопасность.
  - `Day_27`–`Day_30` — законченные обработчики, CLI, безопасность и нагрузка.

- Если хотите вспомнить конкретный пример — откройте папку `Day_N` и смотрите `main.go`.
